# Web App Manual Test Plan

Manual test plan for `cluster-setup/web-app/` (the "Gdansk Public Transport" live map +
Analytics dashboard). Each case lists steps and the expected result. File a bug for any
mismatch, except where the "Known Issues" section at the bottom already explains it.

## Prerequisites

- Cluster running: `docker compose --env-file cluster-setup/env/versions.env --env-file cluster-setup/env/env.dev -f cluster-setup/container/container-compose.yml --profile init up` (first run), plain `up` afterward.
- `gdansk-public-transport-kafka-producer` must have run at least once (only starts with `--profile init`) — otherwise the live map has no vehicles. See `cluster-setup/README-docker.md`.
- Open `http://localhost:3001` (or the EC2 public DNS in prod mode).
- Test in a Chromium-based browser and Firefox at least once each; deck.gl/Mapbox rendering has occasionally diverged between engines.

## Known issues / caveats (expected, not bugs)

- **P4 and P5 dashboard charts ("Daily on-time trend", "Route speed by day") may time out or load slowly.** They aggregate the *entire* table history with no date filter; this is a known, tracked limitation (see `PINOT_IMPROVEMENT_PLAN.md` item 1) — needs a rolling window or a rollup, not something fixable from the web app.
- **Newly added Pinot indexes (sorted column, inverted, range) don't retroactively speed up existing data** until a full OFFLINE backfill re-runs — if query latency doesn't look improved yet, that backfill may not have been executed on this environment. See `PINOT_IMPROVEMENT_PLAN.md` item 1's operational note.
- **Concurrent load**: this cluster runs a single Pinot server replica in dev mode. Don't be alarmed by degraded latency or timeouts if many people/tabs hit the app at once — see the load-test finding in `PINOT_IMPROVEMENT_PLAN.md` item 10 (89% failure rate at 100 concurrent queries is a known, documented cluster-topology limitation, not a web-app bug).
- **Heatmap "hot spots" can land on buildings, not roads** — this is expected GPS/dwell-time behavior (parked vehicles at depots/termini), not a coordinate bug; see prior investigation notes if curious.
