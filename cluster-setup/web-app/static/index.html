Gdansk Public Transport

Welcome to Gdansk Public Transport

This app visualizes live and historical GPS data for every bus and tram in Gdansk. Vehicle positions stream in continuously and are stored for analysis, so you can see what's happening right now and how the network behaves over time.

Live Map

  • Colored dots are vehicles, tracked from live GPS data and redrawn on the map every 10 seconds.
  • Use the route filter dropdown (top-left) to focus on a single line.
  • Click a vehicle to draw its current trip: grey = already covered, light blue = ahead.
  • Click a stop pole to see its scheduled departures and live delays.
  • Toggle Heatmap to see 24 h GPS density instead of live vehicles.
  • Click Ask to ask a question in plain English — it answers using live Pinot data and shows the query it ran.
  • Small badges like 12 ms show how fast that panel's data query ran.

Analytics

The Analytics tab embeds dashboards covering on-time performance, punctuality trends, and rush-hour load across the whole network — built on the same underlying data as the live map.

You can reopen this any time via the ? button in the header.
